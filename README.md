# Русификатор для сборки Create: New Horizon 1.4.3

Этот репозиторий содержит автоматический перевод квестов и предметов для сборки Create: New Horizon. (Часть осталась непереведённой, но лучше чем "вацаонима")

## Установка
1. Скачайте архив с переводом.
2. Распакуйте папки `ftbquestlocalizer` и `kubejs` в (корневая папка игры)\kubejs\assets.
3. Согласитесь на замену файлов, если потребуется.
4. В игре выберите **Русский язык**.

## Особенности
Перевод выполнен с помощью скрипта на базе Google Translate, поэтому содержит множество неточностей. Цветовые коды и технические теги сохранены.
